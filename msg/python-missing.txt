没找到可用的 Python
==================

vocab-ledger 需要 Python 3.10 或更高版本。

如果你还没装：
  1. 打开 https://www.python.org/downloads/
  2. 下载 3.10 以上的版本并安装
  3. 安装第一屏务必勾选 "Add python.exe to PATH"
  4. 装完重新双击「背词.cmd」

如果你已经装了、但双击没反应：
  多半是 PATH 里那个 python 其实是微软商店的占位程序
  （运行时只会弹出「Python was not found; run without arguments to install from the Microsoft Store」）。

  解决办法二选一：
    A. 安装 python.org 的官方版，并勾选 Add to PATH
    B. 打开 设置 > 应用 > 高级应用设置 > 应用执行别名，
       把 python.exe 和 pythonw.exe 两个开关关掉

装好之后，可以在命令行里验证：
    python -c "import sys; print(sys.version)"

能看到版本号，就说明这次真的能用了。
